# 💳 Credit Card Report | Power BI

## 📊 Project Overview

This project is an interactive **Credit Card Report Dashboard** developed using **Microsoft Power BI** to analyze credit card transactions and customer information.

The dashboard provides insights into **revenue, transaction amount, transaction count, interest earned, card categories, customer demographics, expenditure types, and geographic performance**.

The report is divided into two major sections:

- **Credit Card Transaction Report**
- **Credit Card Customer Report**

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze overall credit card revenue and transaction performance.
- Compare revenue across different card categories.
- Analyze transaction and revenue trends over time.
- Understand customer spending behavior.
- Analyze customer demographics and income groups.
- Identify high-performing customer segments and states.
- Monitor interest earned from different card categories and customer segments.

---

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query** for data cleaning and transformation
- **DAX** for calculated measures and KPIs
- **Data Modeling**
- **Excel/CSV** as the data source

## 💳 Credit Card Transaction Report

The transaction report provides analysis of:

- Revenue
- Transaction Amount
- Transaction Count
- Interest Earned
- Card Category
- Expenditure Type
- Education Level
- Customer Job
- Card Type
- Transaction Method
- Weekly and Quarterly Trends

### Revenue by Card Category

The report compares **Blue, Silver, Gold, and Platinum** cards.

**Blue cards** contribute the largest share of revenue, followed by **Silver, Gold, and Platinum** cards.

### Revenue by Expenditure Type

Customer expenditure is analyzed across categories such as:

- Bills
- Entertainment
- Fuel
- Grocery
- Food
- Travel

**Bills** represent the highest revenue contribution among the expenditure categories shown in the report.

### Transaction Method

Transactions are analyzed based on:

- Swipe
- Chip
- Online

This helps understand how customers use their credit cards across different transaction channels.

## 🔍 Key Insights

Based on the dashboard:

- **Blue cards** generate the highest revenue among the card categories.
